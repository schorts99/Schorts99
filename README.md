### Shared Kernel Core
Authored and published the framework-agnostic npm package [`@schorts/shared-kernel`](https://www.npmjs.com/package/@schorts/shared-kernel) in TypeScript. It provides core domain modeling primitives (Value Objects, Entities), distributed authentication contracts, and HTTP abstractions.

**Impact:** Establishes architectural consistency and accelerates service bootstrapping across multi-tenant microservices and independent front-end applications.
